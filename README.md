# Vocalis landing page

A responsive marketing site built with Vite and vanilla JavaScript. Components and content are kept in `src/components.js`; brand and layout tokens are centralized in `src/tokens.css`.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build`.
